## Recommended order

1. Update LinkedIn with [`LINKEDIN_EXACT_UPDATE.md`](./LINKEDIN_EXACT_UPDATE.md).
2. Use the software engineer resume by default.
3. Switch to the QA Automation resume only for clearly automation-heavy roles.
4. Track applications in [`APPLICATION_TRACKER.csv`](./APPLICATION_TRACKER.csv).
5. Use [`RECRUITER_MESSAGES.md`](./RECRUITER_MESSAGES.md) right after applying.

## Notes

- The software engineer resume is the default version for most applications.
- The QA Automation / SDET resume is the secondary lane.
- The materials in this folder are stored in the public `Portfolio` repository, so avoid adding private notes or sensitive personal data to the tracker before sharing the repo.
