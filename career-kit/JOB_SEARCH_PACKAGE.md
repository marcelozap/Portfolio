# Marcelo Job Search Package

This folder contains a consistent set of materials for a software engineering, QA automation, systems, platform, or product-engineering job search.

## Main Positioning

Software engineer with stronger fit for:

- software engineering roles with broader ownership
- QA automation and test engineering roles
- platform or internal tools roles
- product engineering roles
- automation-heavy roles
- systems-oriented roles where reliability and delivery discipline matter

## Files

### Resume

- `RESUME_SOFTWARE_ENGINEER.md` - primary software engineer resume copy
- `Marcelo-Resume-Software-Engineer.txt` - plain-text software engineer version
- `RESUME_QA_AUTOMATION.md` - QA automation / SDET resume copy
- `Marcelo-Resume-QA-Automation.txt` - plain-text QA automation version

### LinkedIn

- `LINKEDIN_REFRESH.md` - fuller LinkedIn rewrite with headline, about, project blurbs, and cleanup notes
- `LINKEDIN_EXACT_UPDATE.md` - direct LinkedIn update copy
- `Marcelo-LinkedIn-Paste-Ready.txt` - simple paste-ready version

### GitHub

- `GITHUB_PROFILE_COPY.md` - GitHub bio options, profile README intro, pinned repo descriptions, and repo one-liners

### Search and Application Execution

- `SEARCH_STRINGS.md` - exact search strings for software engineer and QA automation roles
- `RECRUITER_MESSAGES.md` - outreach and follow-up templates
- `APPLICATION_TRACKER.csv` - tracker for job links, status, and follow-up
- `APPLICATION_WORKFLOW.md` - daily and weekly application workflow
- `COMMON_APPLICATION_ANSWERS.md` - reusable answers for forms and screening questions
- `INTERVIEW_PREP.md` - mock interview and story prep

## Recommended Order

1. Update LinkedIn headline and About using the paste-ready file
2. Update GitHub bio and pinned repo descriptions
3. Use the software engineer resume as the default public resume
4. Use the QA automation resume for SDET or test-heavy roles
5. Make sure the portfolio is deployed with the updated wording

## Best Short Pitch

I'm a software engineer with 4 years of experience across systems, QA automation, analytics, workflow tooling, and independent product builds. I'm looking for a role with more ownership where I can keep growing across systems, platform, product, and automation work.
