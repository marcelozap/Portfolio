# Application Workflow

## Daily target

- 5 strong applications
- 2 follow-up messages
- 1 interview prep session out loud

## For each role

1. Decide the lane:
   - `Software Engineer`
   - `QA Automation / SDET`
2. Use the matching resume.
3. Save the job in `APPLICATION_TRACKER.csv`.
4. Apply.
5. Send a recruiter or hiring-manager message within 15 minutes.
6. Schedule a follow-up 5 to 7 days later.

## When to use each resume

### Software Engineer resume

Use when the role mentions:

- software engineer
- platform
- internal tools
- systems
- workflow automation
- product engineering

### QA Automation / SDET resume

Use when the role mentions:

- QA automation
- SDET
- software engineer in test
- test automation
- release validation
- regression testing

## Fast filter

Apply if the role is:

- remote or hybrid
- 100k+ or likely close
- mid-level
- clearly build-oriented

Skip if the role is:

- manual QA only
- support-heavy with little engineering
- research or ML-heavy
- very senior

## Weekly target

- 25 applications
- 10 follow-up messages
- 2 mock interview sessions
