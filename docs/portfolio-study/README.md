# Portfolio Research Study

This folder is the working study packet for the personal portfolio site.

Purpose:

- Keep the portfolio direction visible while this chat makes edits.
- Track where important code and content live.
- Record current status, open issues, and design rules.
- Preserve XIV identity and editing standards across future passes.

Primary site:

- Live domain: `marcelozapata.dev`
- Local repo: `C:\Users\Green Machine\Documents\Portfolio`
- Framework: Next.js 14, React, TypeScript, Tailwind CSS
- Deployment: Vercel from `main`

Study files:

- [location-map.md](./location-map.md): where pages, components, copy, visuals, and deployment files live.
- [status.md](./status.md): current site state, recent fixes, known issues, and deploy notes.
- [design-standard.md](./design-standard.md): visual, motion, layout, and interaction rules.
- [xiv-editing-standard.md](./xiv-editing-standard.md): XIV language, edit lane, safety, and public-positioning rules.
- [deployment-standard.md](./deployment-standard.md): default push/deploy and rollback workflow for `marcelozapata.dev`.
- [research-log.md](./research-log.md): dated observations and decisions.

Working rule:

This chat can make portfolio edits directly. For `marcelozapata.dev` changes, the default finish is local validation, scoped commit, push to `origin/main`, and Vercel production deploy awareness unless xiv$ explicitly asks for local-only or no deploy.
